# 梯次F_條件判斷：紅石樂園

- 課程時間：09:00－12:00
- 遊戲版本：Minecraft Education
- 程式平台：Microsoft MakeCode
- 核心概念：Agent 控制、物品欄切換、迴圈、條件判斷、方塊偵測、紅石訊號
- 程式狀態：兩個原始程式頁都只有積木截圖，文字程式碼目前缺少；第三個高階程式也沒有來源

> **來源矛盾警告：** 條件判斷積木截圖是重複 `15` 次、偵測 Agent 下方的方塊 ID `152`。第一份原回饋把 `152` 寫成紅石礦石；第二份原回饋則寫前進 `5` 格、偵測左右兩側的鐵礦石 ID `15`。距離、方向、方塊名稱與 ID 都不一致，正式上課前必須確認並實機測試。

## 遊戲內容

### 一、Minecraft 操作與紅石暖身

第一次玩的學生先練習：

- 移動、跳躍、轉動視角與切換物品欄。
- 放置與破壞方塊。
- 使用拉桿、紅石粉、紅石火把、中繼器與紅石燈。
- 召喚 Agent，確認 Agent 的方向與物品欄位置。

老師先示範紅石訊號如何讓紅石燈亮起，以及中繼器的方向會影響訊號傳遞。

### 二、程式一完成後：紅石燈功能驗收

1. 老師替每位學生劃分一條直線實驗區。
2. 依實測結果，把指定紅石元件放入 Agent 物品欄第 1～4 格。
3. 學生完成積木後，在聊天欄輸入 `4`。
4. 觀察 Agent 是否依「前進、切換物品欄、向下放置」的順序完成三組元件。
5. 確認 Agent 後退九格並在起點放置第 4 格物品。
6. 學生實際啟動自己完成的線路，逐段檢查哪些紅石燈亮起。

原資料沒有記錄四個物品欄格位、啟動方式、驗收時間、計分、勝負條件及重置方法；遊戲規則**目前缺少**。

![紅石連接燈成果圖](images/redstone-light-result.png)

### 三、程式二完成後：條件判斷方塊辨識挑戰

1. 老師先用混合方塊排成 15 格測試路線，並確認目標方塊放在 Agent 下方。
2. 學生完成條件判斷積木，在聊天欄輸入 `4`。
3. Agent 每次向前一格，檢查下方方塊是否符合指定 ID。
4. 符合條件時破壞方塊，不符合時繼續前進。
5. 路線完成後，全班檢查被破壞的方塊是否都是正確目標。

截圖中的目標值是 `152`，但原回饋對方塊名稱與 ID 的說明互相衝突。目標方塊、路線配置、時間、得分、誤挖扣分及勝負方式**目前需要確認**。

## 程式內容

### 程式一：放紅石連接燈

老師帶學生完成：

- 使用聊天指令 `4` 啟動程式。
- 先讓 Agent 向上移動一格。
- 使用迴圈重複三次放置流程。
- 每一回合依序切換物品欄第 1、2、3 格，向前移動並向下放置元件。
- 迴圈結束後，Agent 後退九格，切換到第 4 格並向下放置元件。

**教學重點：** 說明迴圈如何縮短重複步驟，以及物品欄切換如何讓 Agent 放置不同紅石元件。

**完成標準：** Agent 能完成九格排列，返回起點並放置第 4 格物品。

**功能測試：** 輸入 `4`，逐一確認移動距離、元件順序、朝向與紅石燈亮起狀態。

**完成後活動：** 學生啟動自己完成的線路，檢查每一段紅石燈是否正常。

**文字程式碼目前缺少，待確認四個物品欄內容並實機驗證。**

### 程式二：if 判斷挖紅石

老師帶學生完成：

- 使用聊天指令 `4` 啟動程式。
- 使用迴圈讓 Agent 重複前進 15 格。
- 每前進一格，偵測 Agent 下方的方塊。
- 使用 `if` 判斷方塊是否等於指定 ID。
- 符合條件時，破壞 Agent 下方方塊。
- 每一回合執行收集全部物品。

**教學重點：** 說明條件判斷讓 Agent 只在符合指定條件時執行破壞。

**完成標準：** Agent 走完測試路線，只破壞指定方塊並保留其他方塊。

**功能測試：** 先確認目標方塊與 ID，再輸入 `4`，逐格檢查破壞結果。

**完成後活動：** 使用自己的程式完成方塊辨識路線，檢查正確率。

**文字程式碼目前缺少，且目標方塊資料互相矛盾，待確認與實機驗證。**
