# 梯次A_迴圈：求生大冒險

## 基本資訊

- **課程名稱：** 梯次A_迴圈：求生大冒險
- **課程時間：** 09:00－12:00，共三小時
- **使用平台：** Minecraft Education、Microsoft MakeCode
- **程式概念：** Agent 控制、方向、序列、迴圈、條件式迴圈、自動採集
- **學生任務：** 編寫砍樹機器人取得木材，實際使用收集到的材料完成樹屋挑戰

## 課前準備

- 開啟 [神木村v6](../shared/maps/神木村v6.mcworld)，並保留一份世界備份。
- 由老師主持世界，確認學生可以加入並使用 MakeCode；需要控制 Agent 時，將學生設為操作者。
- 劃分互不重疊的砍樹區與樹屋建造區，避免 Agent 破壞其他學生的作品。
- 準備一般單格樹幹，以及以2×2樹苗長成的大型杉木、叢林木或深色橡木。
- 可準備骨粉加速樹木生長；深色橡木必須使用2×2四棵樹苗。
- 確認樹木上方沒有建築物，並先實測 Agent 的起點、面向與移動路徑。
- 三個程度使用三份獨立 MakeCode 專案；切換版本前先停止舊程式並清空編輯器。

## 教師備課快速總覽

| 教學階段 | 老師帶學生完成的程式 | 程式完成標準 | 完成後的遊戲或活動 |
| --- | --- | --- | --- |
| 低階 | 用固定次數迴圈砍伐單格樹 | Agent 能向上砍四格並收集木頭 | 使用木材完成迷你樹屋 |
| 中階 | 用迴圈清理2×2大型樹 | Agent 能逐層處理四格樹幹 | 使用大量木材擴建樹屋 |
| 高階 | 用條件式迴圈判斷樹高 | 上方有木頭時繼續、到樹頂時停止 | 挑戰不同高度的單格樹並比較效率 |

## 遊戲內容與規則

1. 學生先練習移動、物品欄、召喚 Agent，以及辨認 Agent 的前後左右與上下方向。
2. 老師依學生程度分配單格樹或2×2大型樹，學生把 Agent 放到指定起點。
3. 學生完成程式後必須在自己的砍樹區實測，確認 Agent 真的能砍伐並收集木材。
4. 學生只能使用自己或 Agent 收集到的木材，在指定建造區完成樹屋。
5. 樹屋至少包含地板、牆面、入口與屋頂；完成後由學生說明使用了哪一種迴圈。
6. 時間到時停止建造，以「結構完整、可正常進出、能說明程式」作為完成標準。

> 程式教學 → Agent 功能測試 → 收集木材 → 實際建造樹屋 → 成果介紹

### 不同程度如何一起參加

- 低階學生使用單格樹取得基本材料，可由老師補充少量木材完成迷你樹屋。
- 中階學生挑戰2×2大型樹，使用較多材料擴建樹屋。
- 高階學生測試不同高度的單格樹，記錄程式是否能在樹頂自動停止。

## 上課知識點

- **Agent 方向：** 所有前、後、左、右都以 Agent 面向為基準，起點放錯就會走錯路。
- **序列：** 程式依照由上到下的順序執行，先破壞、再移動、最後收集。
- **固定次數迴圈：** 已知要重複幾次時，使用 `for` 讓程式變短。
- **條件式迴圈：** 不確定樹有多高時，可以在「上方仍有方塊」的條件成立時繼續。
- **自動化：** 把重複採集交給 Agent，學生就能把時間用在設計與建造。
- **程式除錯：** 先檢查 Agent 起點與面向，再檢查破壞和移動的先後順序。

## 場地準備

- **砍樹區：** 每位學生或每組一條獨立作業線，單格樹與2×2大型樹分區放置。
- **起點標記：** 可在每棵樹前放置金塊，學生站在金塊旁召喚 Agent，並確認 Agent 面向樹幹。
- **樹屋區：** 與砍樹區保持距離，避免 Agent 的破壞範圍碰到作品。
- **重置方式：** 下一輪前重新種植樹苗並使用骨粉，或由老師複製一份備用測試區。

## 低、中、高分級教學

三個程度是三份獨立專案，不可以疊在同一個專案。貼上或建立程式前，先刪除 MakeCode 編輯器原本的內容。

### 低階：單格樹砍伐

- **學習概念：** Agent 方向、序列、固定次數迴圈。
- **聊天指令：** `3`
- **完成標準：** Agent 進入單格樹幹位置，向上砍四格並收集木頭。

```python
def on_on_chat():
    agent.destroy(FORWARD)
    agent.move(FORWARD, 1)
    for index in range(4):
        agent.destroy(UP)
        agent.move(UP, 1)
        agent.collect_all()
player.on_chat("3", on_on_chat)
```

![低階｜砍樹機器人積木](images/tree-cutter.png)

- **測試方式：** 把 Agent 放在一般樹幹前輸入 `3`，確認破壞、移動及收集都有執行。
- **完成後活動：** 使用收集到的木材完成迷你樹屋。

### 中階：2×2大型樹砍伐

- **學習概念：** 將每層2×2樹幹拆成固定移動路徑，再用迴圈逐層執行。
- **聊天指令：** `3`
- **完成標準：** Agent 沿大型樹向上，清理每層四格樹幹並收集材料。

```python
def on_on_chat():
    agent.destroy(FORWARD)
    agent.move(FORWARD, 1)
    for index in range(20):
        agent.destroy(FORWARD)
        agent.destroy(RIGHT)
        agent.move(FORWARD, 1)
        agent.destroy(RIGHT)
        agent.move(BACK, 1)
        agent.destroy(UP)
        agent.move(UP, 1)
        agent.collect_all()
player.on_chat("3", on_on_chat)
```

![中階｜砍超大樹機器人積木](images/giant-tree-cutter.png)

- **測試方式：** 將 Agent 放在大型樹正確起點後輸入 `3`，確認每層四格樹幹都有清除。
- **完成後活動：** 使用大量木材擴建樹屋。

### 高階：自動判斷樹高

- **學習概念：** 使用條件式迴圈，不預先固定樹高。
- **聊天指令：** `3`
- **完成標準：** 上方有方塊時 Agent 持續向上砍伐，到樹頂後停止。

```python
def on_on_chat():
    agent.destroy(FORWARD)
    agent.move(FORWARD, 1)
    while agent.detect(AgentDetection.BLOCK, UP):
        agent.destroy(UP)
        agent.move(UP, 1)
        agent.collect_all()
player.on_chat("3", on_on_chat)
```

- **測試方式：** 分別在兩棵不同高度的單格樹前執行，確認 Agent 都能在樹頂停止。
- **完成後活動：** 比較固定四次與自動判斷樹高兩種程式，說明哪一種適合未知高度的樹。

> 高階程式需先在 MakeCode 切換積木並於 Minecraft Education 實測；通過後再補積木截圖與分享連結。
