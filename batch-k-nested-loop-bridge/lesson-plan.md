## 遊戲內容

學生在神木村點擊「程式挑戰入口」NPC 的「前往 A 點」按鈕進入關卡。需要挑戰中、高階時，學生可沿已完成的橋走到 B 點或 C 點，也可由老師直接手動傳送到指定起點。老師只將正在闖關的學生切換成創造模式；學生依分配使用自己的跑道，把 Agent 放在起點並確認面向終點。

學生從空白 MakeCode 專案逐塊完成程式。執行後先觀察 Agent 是否按照「完成一排四格、回到左側、再前進一排」的順序建造，再親自走過自己完成的平台抵達終點。

抵達 B、C 或 D 點後，學生使用該點 NPC 返回神木村，老師再將該名學生切回生存模式，讓下一位學生進入關卡。已完成的平台會保留，因此每位學生必須使用自己的跑道，不能改走其他學生已完成的路。

### 遊戲準備

- 八位學生各使用一條獨立跑道。
- 初階從 A 點開始；中階從 B 點開始；高階從 C 點開始。
- 中、高階學生可先使用 NPC 到 A 點，再沿已完成的平台前往；也可由老師直接傳送至指定起點。
- 學生執行前先確認 Agent 位於自己跑道的起點並面向終點。
- 老師依學生程度指定水平、往上或往下版本。
- 學生進入關卡後，由老師只將該名學生切換成創造模式，讓 Agent 能持續放置方塊。
- 學生返回神木村後，由老師將該名學生切回生存模式。
- 老師逐一放行學生使用 NPC 或手動傳送進入關卡，避免多人同時操作造成混亂。

### 學生任務

1. 在神木村點擊「程式挑戰入口」NPC 的「前往 A 點」；挑戰中、高階時，再沿已完成的橋前往指定起點，或由老師直接傳送。
2. 到指定跑道後，等待老師將自己切換成創造模式，再確認 Agent 起點與方向。
3. 從空白專案完成自己程度的巢狀迴圈程式。
4. 輸入對應聊天指令，觀察 Agent 建造。
5. 確認平台完整後，走過自己建造的平台抵達終點。
6. 點擊 B、C 或 D 點的 NPC 返回神木村，並由老師切回生存模式。

### 完成與判定

- 平台必須維持四格寬。
- Agent 每完成一排後必須回到同一側，再前進到下一排。
- 平台需延伸 50 排並連接指定起點與終點。
- 學生必須實際走過自己完成的平台，抵達終點才算完成。
- 若 Agent 方向錯誤、尚未切換成創造模式或平台中斷，學生先找出原因再重新測試。

## 程式內容

三個版本都是獨立的學生程式，不放在同一個專案。學生每次從空白 MakeCode 專案開始，依自己的程度完成一份。

共同結構：

- 內層迴圈重複 4 次，負責放置一排四格寬的平台。
- 內層迴圈結束後，Agent 向左移動 4 格，回到下一排的起點。
- 外層迴圈重複 50 次，負責延伸平台長度。
- 水平版只向前移動；往上版額外向上移動；往下版額外向下移動。

### 初階完整程式：水平平台

- 聊天指令：`2`
- 完成標準：Agent 建出四格寬、50 排長的水平平台，學生可以從 A 點走到 B 點。
- 測試方式：輸入 `2`，確認每一排都是四格寬，Agent 每排完成後回到左側並向前延伸。

```python
def on_on_chat():
    agent.move(UP, 1)
    for index in range(50):
        for index2 in range(4):
            agent.place(DOWN)
            agent.move(RIGHT, 1)
        agent.move(LEFT, 4)
        agent.move(FORWARD, 1)
player.on_chat("2", on_on_chat)
```

### 中階完整程式：往上平台

- 聊天指令：`3`
- 完成標準：Agent 建出四格寬、50 排長並持續向上的平台，學生可以從 B 點走到 C 點。
- 測試方式：輸入 `3`，確認每完成一排後 Agent 同時向前及向上移動，平台能連續通行。

```python
def on_on_chat():
```

## 低、中、高分級教學

### 低階

適合年紀小、第一次接觸 MakeCode 或需要較多協助的學生。完成水平平台，理解內層迴圈負責一排、外層迴圈負責延伸即可參加闖關。

### 中階

作為全班預設目標。在水平版的結構上加入向上移動，理解同一個巢狀迴圈如何因方向改變而產生往上平台。

### 高階

適合進度快、年紀大或熟悉 Agent 的學生。在同一個巢狀迴圈中改用向下移動，完成不同高度與方向的進階路線。
