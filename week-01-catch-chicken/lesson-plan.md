## 場地與地圖

- **正式地圖：** [神木村 v6](../shared/maps/神木村v6.mcworld)
- **場地位置：** 本活動不綁定固定座標。老師在開闊、邊界清楚且不影響其他建築的區域設置競賽場。
- **座標記錄：** 到達場地中心後開啟座標顯示，將當天的中心座標寫在白板或課堂紀錄；集合與補充動物時都以此座標為準。
- **場地配置：** 基礎賽只生成雞；進階賽加入牛、羊及蝙蝠。各類動物應分散在相同競賽範圍內。
- **保存方式：** 課前保留一份未使用的世界備份；每梯次結束後重新載入備份，避免前一班的動物數量與場地狀態影響下一班。
- **結構方塊：** 本活動沒有固定建築，不需匯入結構檔。若改用其他地圖，只要重新選定空地並記錄中心座標即可。
- **重置方式：** 清除剩餘動物、重新生成下一回合所需動物，讓學生回到集合點並重新啟動自己的程式。

## 遊戲內容

### 一、Minecraft 操作暖身

進入神木村後，先讓第一次玩的學生完成以下操作：

- 移動、跳躍及轉動視角。
- 開啟物品欄並切換手上的物品。
- 拿取武器並練習攻擊。
- 找到老師指定的集合地點及抓雞比賽區。

熟練的學生可以短暫自由探索或建造簡單房子，但要在程式教學開始前回到集合地點。

### 二、程式一完成後：計分板功能測試

1. 每位學生在聊天欄輸入 `1`，確認畫面顯示「分數歸零」。
2. 每位學生實際擊倒一隻雞，確認分數顯示為 1。
3. 再擊倒一隻雞，確認分數顯示為 2。
4. 如果沒有加分，先回到 MakeCode 檢查事件、變數及程式是否仍在執行。

這一段的目的不是比賽，而是讓學生確認自己寫的程式真的能成為遊戲計分板。

### 三、程式二完成後：全班基礎抓雞賽

**遊戲規則**

- 全班先在同一個起點集合。
- 老師確認所有學生的程式都在執行後，統一倒數「3、2、1」。
- 所有學生同時在聊天欄輸入 `2`，開始 30 秒比賽。
- 只有倒數期間擊倒雞才會得分，每隻雞加 1 分。
- 時間到後停止攻擊，學生回報畫面顯示的最後成績。
- 建議先進行一場練習賽，再進行兩場正式賽，取個人較高的一次作為排名。

**程式如何被實際使用**

- `score` 保存每位學生抓到的雞數。
- `time_left` 控制比賽剩餘時間。
- `if time_left > 0` 確保只有正式比賽期間能得分。
- 最後由程式自行公布成績，不需老師人工計算擊倒數量。

### 四、程式三完成後：進階動物競技賽

**遊戲規則**

- 擊倒雞：加 1 分，是主要得分目標。
- 擊倒牛：扣 3 分，必須避開。
- 擊倒羊：不加分，但獲得 10 秒加速，可用來追雞。
- 擊倒蝙蝠：不加分，受到 5 秒失明，屬於陷阱。
- 全班同時輸入 `2`，進行 30 秒競賽，最後分數最高者獲勝。
- 建議進行一場規則測試，再進行一至兩場正式賽。

這一回合不只比較操作速度，也要求學生理解自己寫下的事件規則，選擇值得追擊的目標。

### 五、程度不同時的進行方式

- **完成低階的學生**：參加由老師協助計時的抓雞賽，仍可使用自己的計分板。
- **完成中階的學生**：參加全班基礎抓雞賽，這是全班預設完成目標。
- **完成高階的學生**：進入進階動物競技賽；其他學生尚未完成時，可先擔任測試員，檢查四種動物事件。
- 若大多數學生都完成高階，最後直接進行全班進階決賽。

### 程式一：基礎計分板

老師依序帶學生理解並完成：

- 建立 `score` 變數，用來保存目前分數。
- 聊天輸入 `1` 時，將 `score` 設為 0。
- 使用「當雞被擊倒」事件，將 `score` 增加 1。
- 將目前分數顯示給玩家。

**教學重點：** 說明「設為 0」是重新開始；「增加 1」是在原本的數字上累加。

**完成後接續活動：** 計分板功能測試。

### 程式二：30 秒限時計分

在基礎計分板的概念上加入：

- 建立 `time_left` 變數保存剩餘時間。
- 聊天輸入 `2` 時，同時重設分數並將時間設為 30。
- 使用迴圈重複 30 次，每次暫停 1000 毫秒並將時間減少 1。
- 使用條件判斷，只有 `time_left > 0` 時擊倒雞才會加分。
- 時間結束後顯示最後得分。

**教學重點：** 讓學生理解變數不只可以保存分數，也可以保存會持續改變的時間。

**完成後接續活動：** 全班基礎抓雞賽。

### 程式三：進階事件規則

在完整的 30 秒比賽中加入：

- 擊倒牛時，`score` 減少 3。
- 擊倒羊時，對玩家套用 10 秒加速效果。
- 擊倒蝙蝠時，對玩家套用 5 秒失明效果。
- 所有特殊規則都必須放在 `time_left > 0` 的條件內，避免比賽外觸發。

**教學重點：** 同一場遊戲可以由多個事件組成，每一種事件都會改變玩家接下來的選擇。

**完成後接續活動：** 進階動物競技賽。

## 實際程式碼

以下三份程式已在官方 Minecraft MakeCode 編輯器逐份貼上，並成功轉換成積木。低、中、高是三個獨立完整版，請依學生程度三選一；貼上前先把編輯器原有內容全部刪除，不可將三份程式疊在同一個專案。

### 低階程式

完成目標：自動計分板。老師負責宣布開始與時間到；學生輸入 `1` 將分數歸零。

- **MakeCode 分享連結：** https://makecode.com/_bcf5ff1tWFJs
- [下載低階 Python](code/low.py)

```python
score = 0

def on_chat_reset():
    global score
    score = 0
    player.tell(mobs.target(LOCAL_PLAYER), "分數歸零")

player.on_chat("1", on_chat_reset)

def on_mob_killed_chicken():
    global score
    score += 1
    player.tell(mobs.target(LOCAL_PLAYER), "分數：" + str(score))

mobs.on_mob_killed(CHICKEN, on_mob_killed_chicken)
```

### 中階程式（全班預設）

完成目標：有開始、30 秒倒數、限時計分與結束成績的完整比賽。學生輸入 `2` 開始。

- **MakeCode 分享連結：** https://makecode.com/_UrCVEHEUa66a
- [下載中階 Python](code/medium.py)

```python
time_left = 0
score = 0

def on_chat_start():
    global time_left
    global score
    score = 0
    time_left = 30
    player.tell(mobs.target(LOCAL_PLAYER), "比賽開始！")
    for index in range(30):
        player.tell(mobs.target(LOCAL_PLAYER), "剩餘時間：" + str(time_left))
        loops.pause(1000)
        time_left += -1
    player.tell(mobs.target(LOCAL_PLAYER), "時間到！最後得分：" + str(score))

player.on_chat("2", on_chat_start)

def on_mob_killed_chicken():
    global score
    if time_left > 0:
        score += 1
        player.tell(mobs.target(LOCAL_PLAYER), "分數：" + str(score))

mobs.on_mob_killed(CHICKEN, on_mob_killed_chicken)
```

### 高階程式

完成目標：在完整比賽中加入扣分、獎勵與陷阱；所有效果只在倒數期間生效。學生輸入 `2` 開始。

- **MakeCode 分享連結：** https://makecode.com/_4AzdibcT2YTV
- [下載高階 Python](code/high.py)

```python
time_left = 0
score = 0

def on_chat_start():
    global time_left
    global score
    score = 0
    time_left = 30
    player.tell(mobs.target(LOCAL_PLAYER), "進階賽開始！")
    for index in range(30):
        player.tell(mobs.target(LOCAL_PLAYER), "剩餘時間：" + str(time_left))
        loops.pause(1000)
        time_left += -1
    player.tell(mobs.target(LOCAL_PLAYER), "時間到！最後得分：" + str(score))

player.on_chat("2", on_chat_start)

def on_mob_killed_chicken():
    global score
    if time_left > 0:
        score += 1
        player.tell(mobs.target(LOCAL_PLAYER), "抓到雞！分數：" + str(score))

mobs.on_mob_killed(CHICKEN, on_mob_killed_chicken)

def on_mob_killed_cow():
    global score
    if time_left > 0:
        score += -3
        player.tell(mobs.target(LOCAL_PLAYER), "打錯目標，扣 3 分！目前分數：" + str(score))

mobs.on_mob_killed(COW, on_mob_killed_cow)

def on_mob_killed_sheep():
    if time_left > 0:
        player.tell(mobs.target(LOCAL_PLAYER), "獲得 10 秒加速！")
        mobs.apply_effect(SPEED, mobs.target(LOCAL_PLAYER), 10, 1)

mobs.on_mob_killed(SHEEP, on_mob_killed_sheep)

def on_mob_killed_bat():
    if time_left > 0:
        player.tell(mobs.target(LOCAL_PLAYER), "碰到陷阱，失明 5 秒！")
        mobs.apply_effect(BLINDNESS, mobs.target(LOCAL_PLAYER), 5, 1)

mobs.on_mob_killed(BAT, on_mob_killed_bat)
```

## 上課知識點

- **變數：** `score` 與 `time_left` 像有名稱的資料盒，分別保存分數與剩餘時間。
- **設為與改變：** `score = 0` 是重設；`score += 1` 與 `score += -3` 是依目前數值增減。
- **事件：** 聊天指令與擊倒不同生物，都能觸發各自的程式。
- **固定次數迴圈：** 重複30次並每次暫停1000毫秒，形成30秒倒數。
- **條件判斷：** `time_left > 0` 限制只有比賽期間能得分或觸發效果。
- **遊戲規則設計：** 雞、牛、羊與蝙蝠分別代表得分、扣分、獎勵與陷阱，讓程式邏輯影響玩家策略。
- **測試與除錯：** 依序檢查開始指令、變數重設、倒數、每一種事件及時間外是否停止計分。
