## 遊戲內容

### 一、Minecraft 操作暖身

第一次玩的學生先練習：

- 移動、跳躍及轉動視角。
- 開啟物品欄並切換物品。
- 尋找沙地及確認 Agent 的位置。
- 召喚 Agent，觀察 Agent 的前、後、左、右、上、下方向。

熟練的學生可以先尋找適合挖沙與建造水電梯的位置，程式教學開始前回到集合地點。

### 二、程式一完成後：收集沙子與製作玻璃

1. 學生把 Agent 放到沙地上方。
2. 在聊天欄輸入 `3`，實際使用自己完成的程式收集沙子。
3. 檢查 Agent 是否向下移動、破壞四個方向並收集方塊。
4. 把收集到的沙子放進熔爐製作玻璃。
5. 收集花朵並製作染料，再製作不同顏色的染色玻璃。

原教案只有活動方向，沒有記錄回合時間、材料數量、得分或勝負條件；競賽規則**目前缺少**。

![玻璃與染色玻璃參考圖](images/glass-reference.png)

### 三、程式二完成後：空中橋、水電梯與天空之城

1. 使用進階版程式擴大挖沙範圍，取得建造需要的沙子。
2. 將沙子燒成玻璃，使用玻璃方塊建造通往空中的橋樑。
3. 使用水與海草製作水電梯；原教案備註水不必逐格放置，可以利用海草處理水源。
4. 搭乘水電梯到空中，在上方建造房子或天空之城。

原教案沒有記錄建造尺寸、完成時間、分組方式、評分標準或勝負條件；成果挑戰規則**目前缺少**。

### 程式一：挖沙子機器人

老師帶學生完成：

- 使用聊天指令 `3` 啟動程式。
- 使用迴圈讓 Agent 連續向下挖掘三格。
- 破壞前、後、左、右四個方向的方塊。
- 使用 `agent.collect_all()` 收集沙子。

**教學重點：** 認識 Agent 的六個方向，以及迴圈如何讓相同動作重複執行。

**完成標準：** Agent 能向下移動三格、破壞周圍沙子並進行收集。

**功能測試：** 將 Agent 放在沙地上方後輸入 `3`，觀察移動、破壞與收集是否都執行。

**完成後活動：** 使用收集到的沙子製作玻璃與染色玻璃。

- [開啟低階完整程式碼](code/low.py)

### 程式二：挖沙子機器人進階版

老師帶學生完成：

- 使用外層迴圈控制兩次挖沙作業。
- 使用內層迴圈讓 Agent 向下挖掘。
- 每次挖掘完成後，讓 Agent 向上三格並向前三格。
- 在下一個位置再次執行挖掘與收集。

**教學重點：** 說明巢狀迴圈與一般迴圈的差別，以及 Agent 如何在完成一個工作區後移動到下一區。

**完成標準：** Agent 能完成第一個挖掘位置、回到地面、向前移動，再執行第二次挖掘。

**功能測試：** 在足夠大的沙地輸入 `3`，確認 Agent 不會被其他玩家或建築阻擋，並能完成兩個位置的動作。

**完成後活動：** 使用擴大收集的材料建造空中橋、水電梯及天空之城。

## 分級教學設計

本梯次使用不同程式作為程度安排，不把低、中、高功能疊在同一個 MakeCode 專案。全班預設目標是完成中階；第一次玩或第一次寫程式的學生完成低階後也能參加材料製作活動。

| 層級 | 適合學生 | 對應程式 | 完成後活動 |
|---|---|---|---|
| **低** | 年紀較小、第一次玩 Minecraft、第一次寫程式 | 挖沙子機器人 | 收集沙子，製作玻璃與染色玻璃 |
| **中（全班預設）** | 大部分學生 | 挖沙子機器人進階版 | 擴大採集範圍，建造空中橋、水電梯與天空之城 |
| **高** | 進度快、年紀較大、操作熟練或參加過多次 | **目前缺少，待討論** | **目前缺少** |
