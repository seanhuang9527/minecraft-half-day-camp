## V9

- **目前用途：** 所有半日營梯次的正式共用地圖

- **已確認新增：** 九人 Agent 天空迷宮
- **玩家觀察平台座標：** `/tp -360 143 235`
- **Agent 跑道座標：** `/tp -360 139 231`
- **場地內容：** 九條並排的石磚迷宮跑道、共用空中觀察平台、外圍防護、跑道隔離，以及九個不同顏色的 Agent 起點。

## 後續版本記錄方式

從 V9 之後，每次發布新地圖時記錄：

1. 發布日期與版本號。
2. 新增、修改或移除的場地名稱。
3. 玩家傳送座標與 Agent 使用座標。
4. 對應的課程或遊戲活動。
5. 是否完成單人與多人測試。
6. 舊版是否保留，以及新版下載連結。
