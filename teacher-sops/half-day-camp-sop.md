## 課前設備與帳號準備

1. 老師與學生電腦都先登入 Minecraft Education，確認版本一致。
2. 老師匯入最新的 [神木村 v8](../shared/maps/神木村v8.mcworld)，並保留一份未上課的原始公版。
3. 開啟 Code Builder，確認 Microsoft MakeCode 可以正常連線與執行聊天指令。
4. 每個程度使用獨立的 MakeCode 專案，避免低、中、高階程式互相覆蓋。
5. 分享連結的匯入方式請參考：[MakeCode 分享連結匯入 SOP](import-makecode-share-link.md)。

## 開啟多人世界

1. 老師使用當日上課用的地圖副本進入世界，選擇「主持人」並開啟多人遊戲。
2. 將加入代碼提供給學生，先讓一台學生電腦加入，確認連線正常後再讓全班加入。
3. 只有需要操作 Agent、程式或場地的學生才設定為操作者；世界規則與全域設定由老師控制。
4. 為每位學生或小組分配不重疊的場地，並說明起點、面向與不可進入的區域。
5. 若學生無法加入，先確認帳號、Minecraft Education 版本與網路，再重新開啟世界及產生新的加入代碼。

## 地圖備份與重置

- 不直接使用原始公版上課。每個梯次都從原始公版建立一份「當日上課用」副本。
- 執行教師地形程式前，先站到教案指定的基準點，確認周圍沒有其他課程作品或學生。
- 場地被破壞或座標錯誤時，停止程式並關閉世界，重新匯入乾淨的地圖副本最穩定。
- 需要保存學生作品時，另外匯出當日世界；不要覆蓋原始公版。
- 結構方塊或教師地形程式的使用方式，以各梯次教案中的「場地、座標與保存」說明為準。

## 常見問題處理

### 學生無法加入世界

- 確認所有裝置使用相同版本與可用帳號。
- 確認學生使用本次世界最新的加入代碼。
- 先讓學生離開登入畫面，再由老師重新開啟多人世界。

### Code Builder 或 MakeCode 沒有連線

- 關閉 Code Builder 後重新按 `C` 開啟。
- 確認 MakeCode 顯示已連接目前的 Minecraft 世界。
- 停止舊專案，再重新開啟本次梯次的專案。

### 輸入聊天指令後沒有反應

- 確認聊天指令、專案版本與教案一致。
- 確認程式已啟動，且沒有同名聊天指令互相覆蓋。
- Agent 類程式再檢查 Agent 的位置、面向、物品欄與學生權限。

### 地形生成在錯誤位置

- 立即停止再次執行相同指令。
- 回到教案指定的基準點，確認玩家站位、朝向及相對座標。
- 若已影響其他場地，關閉世界並重新匯入乾淨副本，不在錯誤地形上繼續上課。
