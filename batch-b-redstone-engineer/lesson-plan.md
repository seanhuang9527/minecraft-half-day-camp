# 梯次B_迴圈：紅石工程師

- 課程時間：09:00－12:00
- 遊戲版本：Minecraft Education
- 程式平台：Microsoft MakeCode Python
- 核心概念：Agent 控制、方向、迴圈、自動挖掘、紅石電力與自動化裝置
- 程式狀態：十字挖礦與魚骨挖礦初階都只有積木截圖，文字程式碼目前缺少；原梯次沒有第三個程式來源

> **備課警告：** 本梯次的名稱與手動活動以紅石為主，但兩個程式頁都是自動挖礦。原資料沒有記錄挖礦程式如何連接紅石活塞門、陷阱門、自動農場或焚化爐，因此不能把這些活動說成程式的直接成果。正式上課前要先決定保留「挖礦程式＋紅石建造」的雙主題安排，或另行補上能控制紅石主題的程式。

## 遊戲內容

### 一、Minecraft 操作、Agent 與紅石暖身

第一次玩的學生先練習：

- 移動、跳躍、轉動視角與切換物品欄。
- 放置及破壞方塊，並把掉落物撿回物品欄。
- 召喚 Agent，確認 Agent 面向及六個移動方向。
- 使用拉桿、紅石粉及紅石燈，觀察紅石訊號的開與關。

老師先用短距離操作指令示範 Agent 的「召喚、轉動、前進」，再讓學生在安全區自由操作。原家長回饋提到這三個基礎指令，但沒有留下對應的獨立程式頁與文字碼。

### 二、程式一完成後：十字礦道採集

1. 老師替每位學生指定彼此分開的礦道起點，並統一 Agent 面向。
2. 學生完成十字挖礦程式後，先在短距離測試區檢查移動與破壞方向。
3. 確認通道安全後，再讓 Agent 完成完整十字礦道。
4. 程式執行完畢，學生親自進入自己完成的礦道採集資源。
5. 學生沿原路返回，向老師說明迴圈替自己省下哪些重複操作。

原教案沒有記錄聊天指令、礦道長度、採集時間、資源得分、勝負條件及重置方法；競賽規則**目前缺少**。

![十字挖礦法原積木截圖](images/cross-mining.png)

### 三、程式二完成後：魚骨礦道採集

1. 老師先播放魚骨挖礦示範影片，說明主幹與分支的形狀。
2. 學生完成魚骨挖礦程式後，先檢查 Agent 是否朝正確方向前進。
3. 程式完成後，學生沿主幹進入自己的魚骨礦道，再依序探索分支。
4. 學生採集找到的資源，並練習從分支回到主幹及起點。
5. 進度快的學生可比較十字礦道與魚骨礦道的探索方式。

原教案沒有記錄聊天指令、主幹與分支長度、採集時間、計分、勝負條件及重置方法；競賽規則**目前缺少**。

### 七、原教案活動：紅石焚化爐

學生手動搭建焚化爐，使用漏斗把物品送入投擲器，再利用比較器、中繼器與紅石訊號控制投擲器，將物品丟入岩漿。

原資料提醒：

- 使用投擲器而不是發射器；發射器會直接使用某些物品，例如射箭或生成生物。
- 放置漏斗並讓漏斗連接投擲器時要按住蹲下。
- 拉桿必須維持打開，裝置才能使用。
- 確認紅石裝置呈現連續閃動且運作正常後，才可封頂。
- 漏斗數量會依裝置向上延伸的高度調整；原清單記錄 4 個。

完成後，學生可把不需要的物品放進箱子，觀察物品是否依序進入漏斗、投擲器與岩漿。原資料沒有記錄測試物品、挑戰時間、計分、勝負條件、重置方式或對應的 Agent 程式；正式遊戲規則及程式關聯**目前缺少**。

### 程式一：十字挖礦法

老師帶學生完成：

- 使用 Agent 的移動與破壞指令建立礦道。
- 使用迴圈縮短重複的「破壞、前進」步驟。
- 透過轉向建立十字形分支。
- 程式完成後進行短距離測試，再進入正式挖掘區。

**教學重點：** 說明迴圈如何取代重複指令，以及 Agent 的面向如何影響礦道方向。

**完成標準：** Agent 能開出可通行、方向正確的十字礦道。

**功能測試：** 先在短距離區測試移動、破壞及轉向，再由老師確認通道安全。

**完成後活動：** 學生進入自己的十字礦道採集資源。

### 程式二：魚骨挖礦法初階版

老師帶學生完成：

- 使用 Agent 的移動、破壞與轉向建立主幹礦道。
- 使用迴圈重複建立左右分支。
- 比較主幹與分支的方向，避免學生在礦道中迷路。
- 程式完成後進行短距離測試，再進入正式挖掘區。

**教學重點：** 說明重複結構如何組成規律的魚骨形狀，以及主幹與分支的關係。

**完成標準：** Agent 能開出具有主幹與分支、可安全通行的魚骨礦道。

**功能測試：** 先確認 Agent 面向，再檢查第一組左右分支是否正確；確認後才執行完整路線。

**完成後活動：** 學生沿主幹與分支採集資源，並回到起點。
