# 梯次C_巢狀迴圈：怪物攻城戰

- 課程時間：09:00－12:00
- 遊戲版本：Minecraft Education
- 程式平台：Microsoft MakeCode Python
- 核心概念：Agent 控制、方向、座標、巢狀迴圈、分層建造、TNT 與基岩特性
- 程式狀態：「炸彈超人」程式頁的積木截圖包含聊天指令 `1`、`2`、`3`，可拆成低、中、高三個延伸步驟；文字程式碼區塊仍為空白

> **安全與交付警告：** 本梯次會使用 TNT、怪物、夜晚模式及玩家對戰。老師必須先備份世界、劃定基岩測試區、確認爆炸選項及遊戲難度，並在學生點燃 TNT 前完成安全說明。現有 `code/` 檔只是缺少項目註記，不可直接當成可執行程式。

> **來源差異警告：** 原文字筆記寫「大迴圈 5、小迴圈 10」，但實際積木截圖的指令 `2` 與 `3` 都是外層 `4`、內層 `4`。本教案以截圖可見的 `4×4` 作為程式說明，同時保留原筆記差異；正式上課前必須實機確認尺寸。

## 遊戲內容

### 一、Minecraft 操作與戰鬥暖身

第一次玩的學生先練習：

- 移動、跳躍、轉動視角與切換物品欄。
- 放置及破壞方塊。
- 召喚 Agent，確認 Agent 的前、後、左、右、上、下。
- 裝備盾牌，練習防禦正面的攻擊。
- 在老師指定的安全區練習投擲及回收三叉戟。

老師先介紹今日任務：用程式建造能承受爆炸的基岩迷宮，再把完成的場地用於 TNT 測試與怪物攻城。

### 二、程式完成後：分層結構功能測試

1. 把 Agent 放到老師指定的建造起點並確認面向。
2. 依老師課前實測結果，把紅石火把、基岩及 TNT 放進正確的 Agent 物品欄格位。
3. 先輸入 `1`，確認 Agent 能完成四格直線放置。
4. 再輸入 `2`，檢查第一個 `4×4` 平面是否完整。
5. 輸入 `3`，檢查 Agent 是否上移兩格並完成第二個 `4×4` 平面。
6. 原文字筆記另寫第一層紅石火把、第二層基岩、第三層 TNT；但截圖只使用物品欄第 1、2 格，第三層 TNT 的程式配置目前缺少，需由老師課前確認或改為手動放置。
7. 在全班離開爆炸範圍後，由老師進行第一次 TNT 功能測試。
8. 檢查 TNT 爆炸後，基岩結構是否保留。

原教案沒有記錄文字程式碼、Agent 物品欄內容、每層精確尺寸、學生站位、點燃方式及場地重置方法；以上內容**目前缺少**。

![基岩與 TNT 分層參考圖](images/bomberman-layers.png)

### 三、基岩迷宮炸怪物與動物

1. 學生使用基岩完成迷宮或封閉測試區。
2. 老師檢查出入口、牆面及玩家安全位置。
3. 老師在迷宮中放入預定的怪物與動物。
4. 學生進入指定位置，以 TNT 解決迷宮中的目標。
5. 每次爆炸後先停止操作，由老師確認場地安全再進行下一回合。

原資料只記錄「讓他們進去基岩裡面炸」及「一開始先放怪物跟動物」，沒有怪物種類、數量、TNT 數量、回合時間、得分、勝負條件或重置方法；正式競賽規則**目前缺少**。

### 四、夜間怪物攻城

1. 老師將世界時間切換為夜晚，並確認難度不是和平。
2. 學生拿著盾牌、三叉戟及老師指定裝備進入自己完成的防禦區。
3. 學生利用基岩結構抵禦怪物，測試程式建造的場地在實戰中是否有效。
4. 回合結束後，全班分享哪一種結構最容易防守。

原教案只有「開晚上」與家長回饋中的夜間打怪挑戰，沒有怪物波次、時間、裝備限制、計分、復活方式及勝負條件；正式規則**目前缺少**。

### 五、原教案結尾：學生 PK

原程式頁記錄「最後是小朋友在裡面 PK」。若老師決定執行，必須先確認所有學生都理解規則、範圍與停止口令，並由老師統一開始及結束。

原資料沒有記錄個人或分組、裝備、TNT 數量、生命設定、淘汰方式、回合時間、計分及復活方式；正式 PK 規則**目前缺少**。若課前未補齊規則，可不執行此段。

## 程式內容

### 程式一：聊天指令 1－四格直線放置

老師帶學生完成：

- 使用聊天指令 `1` 啟動。
- 讓 Agent 向上移動一格。
- 把 Agent 物品欄第 1 格設為使用中。
- 重複四次「向下放置、向前移動一格」。

**教學重點：** 說明單層迴圈如何把同一組放置與移動動作重複四次。

**完成標準：** Agent 能完成連續四格、方向一致的直線放置。

**功能測試：** 輸入 `1`，檢查 Agent 上移高度、使用物品欄及四格放置方向。

**完成後活動：** 逐格驗收，讓學生預測把直線擴展成平面需要再增加哪一層迴圈。

**文字程式碼、Agent 第 1 格物品與實機測試結果目前缺少。**

### 程式二：聊天指令 2－第一個 4×4 平面

老師帶學生完成：

- 使用聊天指令 `2` 啟動。
- 讓 Agent 向上移動一格，選擇物品欄第 1 格。
- 使用外層迴圈重複四列。
- 每一列使用內層迴圈重複四次「向下放置、向前移動一格」。
- 每列完成後，Agent 後退四格並向右移動一格。

**教學重點：** 說明外層迴圈控制列數、內層迴圈控制每列長度。

**完成標準：** Agent 能完成 4×4、共 16 格的第一個平面。

**功能測試：** 輸入 `2`，逐列檢查是否各有四格，且每列向右平移一格。

**完成後活動：** 全班進行 16 格完整度驗收，確認場地第一層沒有缺格。

**文字程式碼、Agent 第 1 格物品與實機測試結果目前缺少。**

- [查看中階缺少項目註記](code/medium.py)

### 程式三：聊天指令 3－第二個抬高的 4×4 平面

老師帶學生完成：

- 使用聊天指令 `3` 啟動。
- 讓 Agent 向上移動兩格，選擇物品欄第 2 格。
- 使用與指令 `2` 相同的 `4×4` 巢狀迴圈。
- 每列完成後，Agent 後退四格並向右移動一格。

**教學重點：** 比較指令 `2` 與 `3` 的高度及物品欄差異，理解同一套迴圈如何重複使用在另一層。

**完成標準：** Agent 能在抬高位置完成第二個 4×4 平面，且與第一層對齊。

**功能測試：** 輸入 `3`，檢查高度、方塊種類、16 格完整度及上下層對齊。

**完成後活動：** 老師確認基岩安全區後，補齊 TNT 配置並進行怪物、動物與夜間攻城活動。

**文字程式碼、Agent 第 2 格物品、第三層 TNT 配置與實機測試結果目前缺少。**
