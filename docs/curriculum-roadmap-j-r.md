# Minecraft 半日營梯次 J～R 主題藍圖

本文件記錄梯次 I 之後九個新梯次的初步規劃。每梯次正式製作時，仍需依三小時半日營規格補齊課前準備、低中高分級、完整 MakeCode Python、程式截圖、功能測試、遊戲規則與家長回饋。

> 狀態：主題規劃草案。除梯次 J 使用 Minecraft Education 官方課程資源外，其餘程式與地圖均尚未實機驗證。

## 規劃原則

- 課程時間為 09:00－12:00，共三小時。
- 每梯次安排 2～3 個程式階段。
- 每個程式完成後，都要直接進入功能測試、遊戲或競賽。
- 中階為全班預設目標；低階學生仍能參加活動；高階學生有新的規則或延伸挑戰。
- 正式製作時一次完成並確認一個梯次。

## 梯次總覽

| 梯次 | 主題 | 可能的程式內容 | 程式完成後的遊戲或成果活動 |
|---|---|---|---|
| J | **梯次J_序列與迴圈：舞台總監** | 排列音符與樂器；控制盔甲座跳舞；設定時間、天氣、舞台與服裝 | 使用官方「The Show Must Go On」世界完成首演，修改程式後進行第二次公演；評選最佳音樂、舞蹈與舞台 |
| K | **梯次K_函式：峽谷救援隊** | 建立搭橋、樓梯及道路函式；使用參數控制橋梁長度；進階加入護欄 | 使用自己的程式修復道路，穿越峽谷、救援村民並運送物資；比較安全性與完成時間 |
| L | **梯次L_隨機數：幸運方塊大冒險** | 產生隨機數；依抽選結果給予物品；加入怪物、增益與陷阱等條件分支 | 啟動自己寫的幸運方塊取得隨機裝備或遭遇陷阱，再進行生存積分賽或競技場挑戰 |
| M | **梯次M_座標：失落神殿尋寶戰** | 認識 X、Y、Z 座標；依座標放置寶箱或檢查點；進階產生多組尋寶座標 | 依程式提供的座標尋找檢查點、取得指定物品並返回起點；以完成時間排名 |
| N | **梯次N_條件判斷：機關密室逃脫** | 輸入密碼開門；檢查玩家是否踩到正確方塊；加入多重條件、提示與錯誤懲罰 | 學生完成機關後交換密室闖關；答對才能前進，答錯則傳回起點、增加怪物或扣除時間 |
| O | **梯次O_事件：魔法競技學院** | 以聊天指令或物品事件施放技能；加入火焰、加速、失明等效果；進階設定技能冷卻 | 先進行魔法打靶，再使用自己寫的技能進行團隊競技、奪旗或保護隊友 |
| P | **梯次P_自動化：快遞物流王** | 控制 Agent 取放物品；設定送貨路線；依站點切換物品欄；進階偵測障礙物 | 控制 Agent 把不同材料送往指定倉庫；比較送貨正確率、完成時間與剩餘物資 |
| Q | **梯次Q_環境工程：洪水防衛戰** | 使用迴圈建造防洪牆；自動挖排水道；偵測水或特定方塊後補牆；進階自動修復 | 完成防洪設施後由老師正式放水；基地內存活的村民、箱子或設備越多，分數越高 |
| R | **梯次R_綜合挑戰：程式地城設計師** | 用函式生成房間；隨機放置寶物與陷阱；加入變數計分、倒數與怪物事件 | 每組製作一座可遊玩的程式地城並交換挑戰；依通關時間、寶物、生命與創意評分 |

## 建議學習進程

`官方引導課程 → 函式 → 隨機數 → 座標 → 多重條件 → 事件 → 自動化 → 環境模擬 → 綜合專題`

## 梯次 J 官方資源

- 課程：Minecraft Education — Hour of Code: The Show Must Go On
- 網址：https://education.minecraft.net/en-us/lessons/hour-of-code-the-show-must-go-on
- 原始課程約一小時，正式改編時需擴充成三小時流程。
- 課程內建音樂、舞蹈、舞台場景及服裝四個程式部門，最後會將學生的選擇整合成正式演出。
- 程式使用官方世界專用的 `hoc` 功能，因此應直接使用官方世界，不可假設能複製到神木村執行。
- 課前需實機確認目前 Minecraft Education 版本、官方世界載入、MakeCode 積木與 Python，以及多人展示方式。

## 後續製作順序

1. 先完成梯次 J 的完整三小時教案。
2. 建立低、中、高三份獨立內容與完整程式。
3. 實機測試所有指令與世界功能，留下對應截圖。
4. 寫清楚每個活動的開始方式、計分、結束條件與重置方法。
5. 確認梯次 J 後，再開始梯次 K。
